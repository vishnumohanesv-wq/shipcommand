# ShipCommand — AWB Command Center

Paste a list of AWB / tracking numbers and get them **auto-classified by courier**, ready to copy in bulk for tracking.

**Live tool:** https://vishnumohanesv-wq.github.io/shipcommand/

## How to use

1. Open the live tool.
2. Paste your AWB numbers (one per line, or separated by commas/spaces).
3. Click **Classify Now** to group AWBs by courier (use **Remove Dupes** first if needed).
4. Copy a single courier's list, or use **Copy All**.
5. Open the courier's tracking page and paste.

## Features

- Auto-classification of AWBs by courier: Movin, BlueDart, Delhivery, Xpressbees, Ekart, DP World, Self, Others
- Accepts new lines, spaces, commas or semicolons between AWBs
- One-click **Remove Dupes** button for repeated AWBs
- Copy per courier (one per line or comma-separated) or copy all
- Live counts per courier plus total
- Quick links to courier tracking pages
- Works on desktop and mobile

## Privacy

Everything runs in your browser. No AWB data is uploaded, stored or sent anywhere.

## Built with

Plain HTML, CSS and JavaScript in a single file. Hosted free on GitHub Pages.

## Update the tool

Edit `index.html` in this repository (pencil icon) and commit. The live link stays the same.

## Disclaimer

Courier detection is pattern-based (prefix/length rules) and may misclassify some AWBs, especially plain numeric ones. Verify on the courier's site before acting on results.
